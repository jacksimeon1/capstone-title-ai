An open-source academic research platform and intelligent capstone project title generator, validator, diagnostic analyzer, and thesis defense assistant designed for undergraduate students, graduate researchers, capstone teams, and academic faculty.

---

## 🌟 Key Features

### 1. Multi-Paradigm Title Generator
- Synthesizes 5–10 defense-ready academic titles from your basic project thoughts across **8 Academic Paradigms**:
  1. **Comprehensive Information Systems** (Enterprise MIS & workflow automation)
  2. **Decision Support & Optimization** (Heuristic & multi-criteria optimization)
  3. **AI-Assisted & Predictive Analytics** (Machine learning & forecasting)
  4. **Cross-Platform Mobile & Cloud** (Offline-first sync & native access)
  5. **IoT & Edge Telemetry** (Sensor networks & automated controls)
  6. **Empirical Usability Evaluation** (ISO/IEC 25010 and 9241 quality models)
  7. **Secure Governance & Auditability** (RBAC, compliance & cryptographic trails)
  8. **Modular Service Architecture** (Microservices & decoupled pipelines)

### 2. Structural Title Analyzer & Weakness Diagnostics
- Evaluates candidate titles across **10 Quantitative Academic Quality Indicators**:
  - Syntactic Clarity
  - Domain Specificity
  - Scope Delimitation
  - Student Feasibility
  - Technical Depth
  - Problem Relevance
  - Target User Definition
  - Innovation & Novelty
  - Research Potential
  - Overall Title Quality Score
- Flags ambiguities (e.g., *Too Generic*, *Scope Too Broad*, *Target Users Unclear*, *Buzzword Inflation*).
- Produces **4 Instant Academic Revisions**: Conservative Academic, Professional Enterprise, Algorithmic/Heuristic, and Empirical Research.

### 3. Prior-Art Conflict & Similarity Detector
- Scans titles against a database of 100+ approved university benchmarks.
- Computes Jaccard lexical overlap and domain keyword correlations.
- Delivers ethical similarity advisories and defense differentiation strategies.

### 4. Idea-to-Concept Blueprint Planner
- Transforms rough project ideas into complete proposals:
  - Background & Problem Statement
  - Technical Architecture & Recommended Tech Stack
  - Feature-to-Complexity Matrix
  - **3NF Normalized Database Schema Design**
  - Project Scope, Explicit Delimitations & Future Work

### 5. Feasibility & Timeline Analyzer
- Tri-pillar feasibility evaluation (Technical, Scope, Timeline for 1 vs 2 semesters).
- Hardware, API, Cloud, and Skillset prerequisites breakdown.

### 6. Multi-Title Comparison Matrix
- Compare 2 to 4 candidates side-by-side with objective trade-off summaries.

### 7. Zero-Account Privacy & Dark Mode Default
- **100% Client-Side**: No login, sign-up, or accounts required. All projects and favorites persist privately in browser `localStorage`.
- **Default Dark Mode**: Launches with an academic slate dark theme, complete with a top-bar Sun/Moon toggle.
- **Export Formats**: PDF (jsPDF), Markdown (`.md`), and raw text (`.txt`).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript (Vite 8)
- **Styling**: Tailwind CSS with custom academic palette and class-based dark mode
- **Icons**: Lucide React
- **Document Generation**: jsPDF
- **Storage**: Client-Side HTML5 LocalStorage

## 🚀 Quickstart

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the public repository
git clone https://github.com/jacksimeon1/capstone-title-ai.git

# Navigate into project directory
cd capstone-title-ai

# Install dependencies
npm install

# Launch local development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
